15 分钟上手

四步：装 → 粘简历 → 下载语音模型 → 开面试。第一次会多花两三分钟，之后每次打开就能用。

① 下载并安装

  1. 在首页点「下载 Windows 版」，下载完成后双击安装包。
  2. Windows 可能弹「已保护你的电脑」（SmartScreen）：点 更多信息 → 仍要运行。软件没有购买数字签名证书，这一步是正常的。
  3. 安装过程不弹 UAC，默认装到你的用户目录，不需要管理员权限。
杀毒软件报毒？ 软件会读取系统播放的声音（用于识别面试官提问），这类行为和录音软件相似，容易被启发式规则误报。如果被拦，把安装目录加入信任区再运行。截图位：SmartScreen「更多信息 → 仍要运行」

② 首次设置（4 步）

第一次打开会进向导，四页都是能跳过的，但建议按顺序走完：

步骤做什么说明
① 简历把简历全文粘进来面试时模型只按这里写过的内容作答，不会编造项目。写清楚比写长重要。
② 语音模型点「下载语音模型」约 226 MB，国内通常 1 分钟内下完；只需下一次。
③ 作答通道默认「内置（免配置）」不用注册、不用填 Key；想换更强模型再切自己的 Key。
④ 声音来源自动探测，确认两行都打勾「系统声音（面试官）」和「麦克风（我自己）」都找到就对了。
截图位：向导第 4 步自动探测出的两行设备名

③ 记住四组热键

热键作用
Ctrl+Shift+J开始 / 停止面试监听（点开始才开始计时）
Ctrl+Shift+X笔试截图解题（全屏截图）
Alt+Shift+A区域截屏解题（只截题目那一块）

Ctrl+Shift+L纠错·打字（直接把正确的问题打进去）

④ 先拿一段音频试一遍

不用真的开会也能验证：在电脑上放一段别人提问的音频（B 站面试视频即可），按 Ctrl+Shift+J，看浮层是否出现「面试官 · 问题」和随后的答案。能出字，说明采集、识别、作答三段都通了。

2安装与首次设置

装在哪、卸载会不会丢数据

默认装到 %LOCALAPPDATA%\Programs\QianmianAI，不写系统目录。卸载只删程序文件，简历、经历要点、术语表、面试记录都保留；想彻底清干净，卸载后手动删掉安装目录即可。

余额与时长存在本机（billing.db）。换电脑、重装系统不会自动带走，需要联系作者补发。不要手动删这个文件：删掉后软件会判定计费数据缺失并拒绝启动。

三种作答通道怎么选

通道适合谁模型费用
内置（免配置）不想折腾、直接开始用作者承担（DeepSeek Flash）
智谱 GLM（免费）想完全零成本、能接受高峰期偶发限流免费
DeepSeek / 百炼（付费）要求稳定、要更强模型你自己充值
自定义已有其他厂商 Key（OpenAI 兼容接口）你自己充值

切换在 托盘菜单 → 设置… → 作答，改完记得重启软件。

语音模型下载失败怎么办

向导第 2 步有进度条，断了可以重试。一直失败时，在安装目录打开命令行手动下：

python tools/download_asr_model.py --model-dir "models/sherpa-paraformer-bilingual"

没有 Python 就换个网络（手机热点）再点重试——下载源是 ModelScope，走的是国内节点。

软件没有托盘图标 / 打不开

  • 看是否已经在运行：重复双击会提示「已在运行」，从托盘图标打开即可。
  • 打不开时看日志：安装目录下 logs\crash-*.log 与 logs\app-*.log，最后几行通常直接写明原因。

3实时面试

先选对「声音来源」

这一步决定答案准不准，比换模型重要得多。设置 → 采集：

你的场景选这个为什么
电脑开会议（腾讯会议 / 飞书 / Zoom），戴耳机两路分离系统声音=面试官、麦克风=你自己。只有面试官提问才作答，你自己说话不会触发答案。
只用电脑外放，不戴耳机仅系统声音麦克风会把外放的声音再收一遍，容易重复触发。
面试在手机上，电脑只用来显示答案手机当麦克风（双流）手机浏览器打开提示的局域网地址开始录音；手机那路当面试官、电脑麦克风当自己。
为什么推荐「两路分离」：它能把「面试官」和「我」分开。分开之后才有两件事——你自己说话不会触发答案；识别错了可以按 Ctrl+Shift+K 复述纠正。单流模式下这两件事都做不到。

答案为什么要等 1.5 秒

面试官说话中间会停顿（换气、想词），语音识别会把停顿当成「一句说完了」。如果每识别到一句就作答，会出现「话说一半就出答案，说完又出一个新答案」。

所以软件会等：识别到提问后，再安静 1.5 秒才作答；期间又来新内容就合并成同一个问题。这 1.5 秒是故意等的，不是卡。

  • 觉得太慢：设置 → 作答 → 静默窗口，可调到 1.0–1.2 秒（再低会重新出现「话说一半就答」）。
  • 觉得太急：调到 2.0 秒。

「嗯」「对」「OK」不会触发答案

纯语气词、以及剥掉语气词后不足 4 个字且不像提问的碎片，会被直接忽略，状态行显示「听到填充词，已跳过」。「请继续」「接着说」这类明确指令会正常作答。

旧答案不会被刷掉

浮层按轮追加：每一轮是「面试官 · 问题 + 答案」，历史问答保留在上面。内容太长时只裁掉最早的轮次。

识别错了怎么办（两层纠正 + 一个人工通道）

  1. 自动纠错（默认开）：识别出的技术名词会按你的术语表校正，比如把「信客连 map」改成「sync.Map」。它藏在 1.5 秒等待里，不额外增加延迟。
  2. 我的术语（最有效）：托盘 → 我的资料 → 我的术语。一行一个词，尤其是英文专有名词（vLLM、KV cache、PolarDB-X）。写进去的词会被优先纠正，改完不用重启。
  3. 人工纠错：错得离谱时——按 Ctrl+Shift+K，把问题重说一遍（12 秒内有效，只取下一句）；或按 Ctrl+Shift+L 直接把正确问题打进去。重答是追加新一轮，看最下面那轮就行。
识别准确率的边界：本地识别对「中文口音念英文缩写」天生不擅长（GMP、vLLM、KV cache 这类）。写进「我的术语」是目前最有效的办法；云端识别更准但音频会上传，且按小时计费。

计费规则（只在这一节讲清楚）

  • 点「开始面试」才开始计时，之前调试设备、试麦克风都不计费。
  • 开始时先预扣 5 分钟作为押金，停止时按实际分钟结算，多退少补（不足 1 分钟按 1 分钟）。
  • 没有暂停：停止=本场结束；再开是新的一场。
  • 软件崩溃/被强杀：下次启动会按心跳时间自动结算，不会白扣押金。
  • 使用时段卡时，有效期内开场不扣分钟（单日上限 8 小时，超出后回落按分钟计费）。

答案怎么看、怎么用

  • 答案是口语稿，不是书面报告：直接照着说，别念成朗读稿。
  • 每轮自动落盘：托盘 → 网页版记录…，浏览器打开后可以按日期翻历史、搜索关键词、看被过滤的寒暄与设备调试。
  • 浮层可点击穿透（Ctrl+Shift+T），也能从录屏里排除。

4笔试截图

两种截法

热键截什么什么时候用
Ctrl+Shift+X整块屏幕题目在页面中间，或有多道题一次看完
Alt+Shift+A你框选的一块小字、代码块、只有一道题 —— 推荐，字更大更准
字小看不清就框选：模型是按像素读字的，截图里字太小会读错。先框选题干那一块，比整屏效果好很多。

输出长什么样

  • 代码题：先给 3–5 条思路要点，再给完整可运行代码，最后一行是结论。
  • 选择题：先用 2–4 句说判断依据（为什么选它、排掉了哪些），再给最终选项，最后一行是「答案：X」。

用哪个模型

托盘 → 设置 → 作答 → 通道 / 模型档位。默认内置通道已经是「单次看图直接解」；想更稳可以切 DeepSeek 的 reasoner 档（先抄题再解，慢几秒但复杂题更准）。

常见情况

  • 截图后没反应：热键被别的软件占了。到设置里换一个热键，或从托盘菜单点「笔试截图解题」。
  • 答案只给结论没有过程：确认选的是「代码题 / 选择题」判断正确的题型；实在判断错，直接在截图里把题干框全一点。
  • 多显示器：全屏截图只截主屏，副屏请用区域截屏。

6常见问题

会被面试公司发现吗？

软件把浮层从屏幕录制和截屏里排除了，任务栏也能隐藏。但这不等于「绝对检测不到」：你的作答内容、语速、停顿才是主要破绽。是否允许使用 AI 辅助，取决于招聘方的规则，风险由使用者自负；作者不承诺任何「防检测」效果。

需要联网吗？

语音识别在本地跑，没网也能出字幕；但生成答案要联网（要走你选的模型通道）。完全断网时只能用「打字提问 + 本地模型」这类自建方案。

用的什么模型？

内置通道默认 DeepSeek V4.1 Flash（快速档、关闭思考）。可以切智谱免费档，或填自己的 Key / 自定义 OpenAI 兼容服务。

支持 Mac / 手机吗？

客户端是 Windows 10/11。手机可以用两件事：当麦克风（手机浏览器开提示的地址录音，答案仍显示在电脑），以及看记录（电脑上打开网页版记录后，手机连同一个 Wi-Fi 访问局域网地址）。手机端暂时没有独立的作答 App。

一个兑换码能用几台电脑？

一个码只能兑换一次。换电脑要重新买/联系补发。

为什么第一句话出得慢？

正常链路是：识别到完整问题 → 等 1.5 秒确认说完了 → 模型开始出字（首字约 0.6–0.9 秒）。所以从面试官说完到看见第一个字，大约 2 秒多。中途如果他又补充了一句，会重新计时。

为什么答案有时候答非所问？

九成是识别错了关键词（把「GMP」听成「简品」这种）。按第 3 节的顺序处理：先把词写进「我的术语」，再用 Ctrl+Shift+K 复述或 Ctrl+Shift+L 打字。

可以截图/录屏吗？

可以。浮层默认不出现在录屏与截屏里；如果对方要求共享整个屏幕，先按 Ctrl+Shift+T 或从托盘隐藏浮层。

退款怎么算？

未开始使用的时长包 7 天内可全额退；已使用的按剩余部分协商。时段卡一经开通不退。具体以购买时的说明为准，直接邮件联系。

能同时开两场面试吗？

不能。同一台电脑只允许一个实例运行，重复打开会提示「已在运行」。

7故障排查

按「症状 → 先看哪 → 怎么修」查。修不了就带上日志发到支持群/邮箱。

症状先确认处理
按了开始，浮层不出字 状态行写的是「正在监听 设备名」吗？ ① 确认会议软件有声音输出（放首歌试试）；② 设置 → 采集，换「两路分离」→ 重启；③ 蓝牙耳机切换输出设备后，需要重新开始一场。
出字了但一直没答案 状态行是否提示「余额不足」 余额不足 → 设置 → 账户兑换；若提示「未配置 Key」→ 设置 → 作答 选回「内置」。
答案答非所问 浮层上那句问题是不是就错了 是识别错 → 术语表 + 纠错热键（见 3.5）。问题本身对但答案跑偏 → 检查「我的资料 → 简历/经历要点」是否写了无关内容。
提示「语音识别已切换离线桩」 模型是否下载完 向导第 2 步重新下载模型；下载完重启软件。
提示限流 / 请求失败 是否用了免费档 免费档高峰期会 429：等 30 秒重试，或在设置里切到内置/自己的 Key。
软件打不开 / 一闪就退 logs\crash-*.log 最后 20 行 最常见是杀软拦截或模型目录被删。加白名单、重下模型；仍不行把日志发过来。
提示「软件无法继续使用」 是否手动删过 billing.db 或改过余额 这是完整性校验。联系作者核对记录后恢复，不要自己再改文件。
网页版记录打不开 安装目录是否有 jre\ 与 webserver\*.jar 是精简安装包的情况请联系作者；端口 8766 被占用时先关掉占用程序再点一次。
发问题前顺手做三件事，能省一个来回：① 截图浮层 + 状态行；② 附 logs\app-*.log 最后 50 行；③ 说明「哪个模式（两路分离/仅系统声音/手机）/ 哪个通道（内置/免费/自备 Key）」。

8隐私与使用边界

音频去哪了

语音识别在本机完成，音频不上传（默认本地模型）。开启录音留档时，wav 只写在本机 logs\audio\，默认关闭。

文字去哪了

生成答案时，会把「简历 + 经历要点 + 你的术语 + 最近几轮对话 + 当前问题」作为文本发给模型服务：

  • 内置通道：走作者提供的 Key，文本会经过作者的模型账户（作者能看到调用量，不保存你的简历原文）。介意就切自己的 Key。
  • 自备 Key / 自定义：直接发给你配置的厂商，作者这一侧看不到。

记录存在哪、怎么删

  • 面试记录：安装目录 logs\interview\sessions\（JSON + Markdown）。
  • 日志：logs\app-*.log；崩溃日志 logs\crash-*.log。
  • 想清空：直接删这些文件即可，不影响软件运行（余额在 billing.db，别删）。

使用边界

本软件用于面试练习、复盘与笔试解题辅助。是否允许在真实面试中使用 AI 辅助，由招聘方规则决定，请自行判断并承担相应风险。作者不对因使用本软件导致的任何招聘结果、账号处罚或纠纷负责。
