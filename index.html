为什么不一样

三件别人不一定做的事

✓
音频不出本机。 语音识别跑在你自己的电脑上，只有文字会发给你配置的模型服务商。不录音、不上传音频。
✓
听得懂中式英语。 内置术语纠错层，GMP、sync.Map、InnoDB 这类被识别成"简品""信客连"的词会被还原，而不是照着错词答偏。
✓
只讲你简历里写过的事。 答案锚定在你自己的经历要点上，不会给你编一个"我在阿里做过"的项目——那种一追问就露馅。

常见问题

装之前先看这几条

安装时提示"Windows 已保护你的电脑"怎么办？

这是 Windows 对未签名程序的默认拦截，不是病毒。点「更多信息」→「仍要运行」即可。代码签名证书一年一千多，现阶段还没买，所以每次新版本都会出现这个提示。

杀毒软件报毒？

本程序会采集系统播放的声音（用于实时识别），这类行为容易被启发式引擎误判。加入信任目录即可。程序不联网上传音频，也不需要管理员权限。

需要自己准备 API Key 吗？

需要。模型调用走你自己的账号（DeepSeek 等），费用由你自己的账单结算。这是刻意的设计——你的面试内容不经过我们的服务器。

装完有多大？

安装后约 470 MB，其中 237 MB 是本地语音识别模型。模型随安装包一起装好，不需要首次运行再下载 200 多 MB。

支持 Mac 吗？

目前只做 Windows 10 / 11 64 位。

能退款吗？

购买 7 天内且未开始使用，可全额退；已使用的时长不退。
