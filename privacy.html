《千面 AI 隐私政策》

本政策说明千面 AI（下称「本软件」）在你的 Windows 电脑上读取什么、采集什么、把什么发出去、把什么留在本地，以及你可以如何管理这些数据。

生效日期：2026-11-23 · 适用版本：v0.2 及以后 · 适用平台：Windows 10 / 11

一我们收集什么

本软件是装在你自己电脑上的桌面程序，不是云端服务。绝大多数数据都在本机处理，只有你在配置里指定的第三方模型服务商才会收到内容。具体分四类：

1. 你放在安装目录里的资料文件

为了让作答贴合你的真实经历，本软件在生成回答时会读取安装目录下的以下文本文件（文件不存在时按空处理，不会报错）：

文件内容用途
resume.txt你的简历正文作答时作为「你写过的事」的上下文
jd.txt目标岗位描述让回答贴近岗位要求
profile_notes.md「我的经历要点」口袋卡补充简历外的经历细节
这些文件由你自己创建和维护，本软件只读取、不修改、不上传到作者服务器。

2. 面试模式下的系统音频

开启实时面试（默认热键 Ctrl+Shift+J）后，本软件通过 Windows 的 WASAPI 回环采集读取「系统正在播放的声音」，也就是面试官从会议软件、浏览器或播放器里传出的声音。音频会被重采样为 16 kHz 单声道用于语音识别。

  • 本地识别模式（ASR_PROVIDER=local，或 auto 且本机已下载语音模型、未配置云端 Key）：识别在本机用 sherpa-onnx 完成，音频不出本机。
  • 云端识别模式（ASR_PROVIDER=dashscope，或 auto 且配置了阿里云百炼 Key）：音频会发送到阿里云百炼（DashScope）做实时语音识别。只有在你主动选择/配置了云端识别时才会发生。
  • 不开启面试监听时不采集；音频仅用于实时识别，默认不保存为录音文件。

3. 需要模型作答的文字与截图

  • 面试作答：识别出的问题文字，连同简历、岗位描述、经历要点和最近几轮对话，作为文本发给作答模型。
  • 笔试截图：按下截图热键后，截取的屏幕图像会发给视觉模型（VLM）读题、解题。截图前悬浮窗会短暂隐藏，避免把浮层拍进去。
  • 底部输入框：你手动粘贴或输入的题目，作为文本发给作答模型。

4. 本机运行记录

运行日志、对话归档、计费账本等全部写在你自己的磁盘上，不上传（详见「四 · 存在哪里」）。

二为什么处理这些数据

  • 读简历 / JD / 经历要点：让回答锚定在你真实写过的经历上，避免编造项目。
  • 采集系统音频：把面试官的问题转成文字，这是实时面试功能的前提。
  • 把文字 / 截图发给模型：由你配置的大模型生成作答或解题结果。
  • 写日志与归档：便于你面试后复盘、排查故障；计费数据用于记录你的剩余时长。

本软件不做用户画像、不做行为分析、不做广告投放。

三这些数据发给谁

数据只会发给你在设置里自己配置的服务商，作者不参与转发。按功能分：

数据接收方触发条件
语音（音频流）阿里云百炼 DashScope（实时语音识别）仅当 ASR_PROVIDER=dashscope，或 auto 且配置了百炼 Key
问题文字 + 简历 / JD / 对话上下文你选择的作答模型服务商（如 DeepSeek、智谱、阿里云百炼，或自定义 OpenAI 兼容服务）每次生成作答时
屏幕截图你选择的视觉模型服务商（VLM）按下笔试截图热键时
本软件不会把音频上传到作者的服务器。作者没有为本软件架设收集数据的后端；模型调用走的是你自己的 Key 或安装包内置的 Key，数据直接在你的电脑与服务商之间传输。第三方服务商如何处理这些数据，受其各自的隐私政策约束。
没有遥测 / 统计分析。本软件不集成 PostHog、Sentry、Google Analytics 等任何第三方埋点。唯一的可观测上报是 LangFuse 追踪，且默认关闭——只有在环境变量里显式设置 LANGFUSE_ENABLED=true 并填好自部署实例地址与密钥时才会启用，属于开发者自用调试功能。

四数据存在哪里

安装版默认安装在用户目录下（如 %LOCALAPPDATA%\Programs\QianmianAI），数据文件跟随安装目录：

内容位置说明
运行 / 崩溃日志logs\app-*.log、logs\crash-*.log按天分文件、超限轮转；日志中不写入任何 API Key 原文
对话归档logs\sessions\（JSON 与 Markdown 镜像）每轮问答的成功结果按对话保存，便于复盘
计费 / 余额数据billing.db本机 SQLite 账本，记录剩余时长、时段卡与兑换核销
你的配置与资料.env、resume.txt、jd.txt、profile_notes.md 等由你维护，本软件读取
  • 全部留在本地。没有云端备份，也没有跨设备同步。
  • 保留期限：本软件不做自动过期清理，数据一直保存在本机，直到你手动删除或卸载。
  • 删除方式：直接删除 logs\ 目录即可清空日志与对话归档，不影响软件运行。注意 billing.db 是计费账本，不要手动删除或修改，否则软件会因完整性校验失败而拒绝启动；如需处理请先联系作者。
  • 卸载：卸载程序只删除程序文件，你所填写的简历、经历要点、术语表与面试记录会保留。想彻底清除，卸载后手动删除安装目录即可。

五你的权利

由于数据都保存在你自己的设备上，你对自己的数据拥有完全控制权：

  • 知情：你可以在本政策与「文档 → 隐私与使用边界」中了解数据的完整流向。
  • 查阅：简历、归档、日志都是明文文件，随时可用任意编辑器打开查看。
  • 删除：删除 logs\ 下的文件即可清除本地记录。
  • 限制发送：把语音识别切到「本地（离线）」即可让音频完全不出本机；不填云端模型的 Key、或断开网络，就不会有文字发出。
  • 撤回：不确定是否继续使用时，停止使用并卸载即可。
已经发送给第三方模型服务商的内容，需要按该服务商的隐私政策向其行使删除等权利，作者无法代为删除。

六未成年人

本软件面向有求职、面试练习需求的用户。若你未满 18 周岁，请在监护人陪同与同意下使用，并由监护人协助理解本政策与《用户协议》。本软件不主动面向未成年人收集个人信息。

七政策变更

本政策可能随功能调整而更新。发生重大变更（例如新增数据接收方、改变音频处理方式）时，会在本页面更新「生效日期」并通过软件更新说明告知。继续使用即视为接受更新后的政策。
