下载与安装

两个拦截提示，都不影响正常使用

本软件尚未购买数字签名证书，也没有做任何隐藏或加壳处理，因此 Windows 的 SmartScreen 与部分杀毒软件 可能给出提示。按下面两步操作即可正常安装运行。

1

「Windows 已保护你的电脑」怎么继续

双击安装包后，若弹出蓝色的「Windows 已保护你的电脑」窗口，这是 Windows 对未签名程序的默认拦截，不是病毒。按以下顺序操作：

  1. 点击窗口中的 「更多信息」（More info）链接，展开被折叠的按钮；
  2. 点击右下角的 「仍要运行」（Run anyway）；
  3. 安装向导继续，按提示完成安装即可。
截图位：SmartScreen 窗口 →「更多信息」→「仍要运行」
为什么会出现：代码签名证书需要每年付费，现阶段尚未购买，所以每个新版本首次运行时都会出现这个提示，属于正常现象。
2

杀毒软件误报时怎么加信任

本软件会读取系统正在播放的声音（用于实时语音识别），这类行为与录音软件相似，容易被启发式引擎误判为风险。若被拦截，请把安装目录加入杀毒软件的信任 / 排除列表，再重新运行。

  • Windows Defender：「Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项 → 添加排除项 → 文件夹」，选中安装目录。
  • 第三方杀软（火绒 / 360 等）：在「信任区 / 白名单 / 排除目录」里添加安装目录。
截图位：杀毒软件「添加信任目录 / 排除项」界面
提示：把整个安装目录加进信任区即可，无需关闭杀毒软件。安装目录通常是 %LOCALAPPDATA%\Programs\QianmianAI；若不确定位置，可在开始菜单右键本软件图标 →「打开文件所在的位置」查看。
